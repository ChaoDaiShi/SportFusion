# 全报告图表清单

> **文档性质**：报告视觉内容的生产计划——每张图表须支撑独立结论、标注数据来源和风险、区分正文/附录/删除。  
> **准则依据**：准则9（图表只能从正式数据自动生成）、准则10（没有完成的内容明确标记）

---

## A. 图表制作准则

1. 所有定量图表由脚本从正式CSV/JSON生成，禁止手工修改柱高、标签、比例
2. 每张图表须支撑至少一个独立结论，否则删除或并入其他图
3. 样本量<20的分类不做图，改为表格或案例说明
4. 数据口径未锁定（🟡）的图表，暂缓制作
5. 四状态标记：✅已生成复核 / 🟡待生成(数据就绪) / ❌阻塞(数据不足) / ⬜纯框架(无需数据)
