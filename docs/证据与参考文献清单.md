## B. 证据等级说明

| 等级 | 含义 | 可支撑结论类型 | 示例 |
|:----:|------|---------------|------|
| **A** | 原始数据 + 源码 + 可复算输出 | 事实陈述、数量比较 | 76,687家企业 / 8,950家候选 / SportRatio公式 |
| **B** | 正式实验或辅助核验 | 效果评估（带方法说明） | 辅助核验一致率 / 消融实验结果 / 效率测试 |
| **C** | 官方政策、标准、权威文献 | 背景、政策依据、分类参考 | GB/T 4754-2017 / 国发〔2014〕46号 |
| **D** | 项目推断或解释 | 分析性结论（须标记为推断） | "产业边界扩展""传统统计遗漏原因" |
| **E** | 规划或未验证观点 | 仅限展望章节 | "引入大语言模型""多年度趋势监测" |

> ⚠ 正文结论应尽量依赖A—C级证据。D级必须写成推断（"可能""推测""估计"），E级只能进入第九章展望。
