## C. SportRatio定义与边界

### C.1 公式（源码 `sport_recognition.py` 第141行）

```
sport_ratio = min(0.40×W1 + 0.25×W2 + 0.25×W3 + 0.10×W4, 1.0)
```

| 维度 | 权重 | 计算公式 | 取值范围 |
|------|:----:|------|:--------:|
| W1 业务范围占比 | 0.40 | sport_line_count / total_lines | [0, 1] |
| W2 关键词密度 | 0.25 | min(sport_hit_count / token_count × 10, 1.0) | [0, 1] |
| W3 行业代码权重 | 0.25 | direct=0.85, indirect=0.30, none=0 | {0, 0.30, 0.85} |
| W4 业态覆盖度 | 0.10 | len(matched_sport_categories) / 9 | [0, 1] |

### C.2 SportRatio理论最大值

W4理论上可达1.0（源码未限制最多覆盖几类业态），因此：

```
理论最大值 = 0.40×1.0 + 0.25×1.0 + 0.25×0.85 + 0.10×1.0 = 0.9625
```

> **v2.0错误**：v2.0错误假设W4上限为5/9=0.5556，得出0.9181。正确值为0.9625。

### C.3 实际数据中的SportRatio

| 指标 | 数值 | 说明 |
|------|:----:|------|
| 数据中观察到的最大值 | **0.8847** | 28家企业达到此值 |
| 数据中观察到的最大W4 | **4/9 = 0.4444** | 实际数据中最多的业态覆盖为4类 |
| SportRatio均值(候选企业) | **0.6471** | 来自model_validation |
| 数据中无sport_ratio=1.0的记录 | — | v2.0中"可能由截断产生"的说法不成立，已删除 |

### C.4 SportRatio实际分布特征（重要局限性）

8,950家候选企业中，前4个固定取值覆盖了 **8,848家（98.86%）**：

| SportRatio | 企业数 | 占比 | 形成原因 |
|:----------:|:------:|:----:|----------|
| 0.8736 | 5,225 | 58.4% | 直接代码 + 单条文本命中（W1=1,W2=1,W3=0.85,W4=1/9） |
| 0.2125 | 2,730 | 30.5% | 直接代码 + 文本未命中（W1=0,W2=0,W3=0.85,W4=0） |
| 0.6611 | 846 | 9.5% | 非体育代码 + 单条文本命中（W1=1,W2=1,W3=0,W4=1/9） |
| 0.7361 | 47 | 0.5% | 间接代码 + 单条文本命中（W1=1,W2=1,W3=0.30,W4=1/9） |
| 其他 | 102 | 1.1% | 多业务线/多关键词/多业态等复杂情形 |

> **局限性声明**：SportRatio在形式上连续（[0, 0.9625]），但在实际数据上高度离散，接近"四档评分"。这主要由两个原因造成：
> 1. 99.11%的候选企业只有1条业务线，W1退化为二元值（0或1）
> 2. 短文本中单个体育词即可使W2饱和（关键词密度放大系数10导致W2=1）
>
> 报告中不应过度强调"实现了连续比重精准测算"，建议表述为"构建了基于业务描述特征的体育涉入评分"。

### C.5 W1/W2饱和分析

| 指标 | 数值 | 说明 |
|------|:----:|------|
| 候选企业仅1条业务线 | **8,870家 (99.11%)** | W1退化为二元判断 |
| W1=1.0的企业 | 6,153家 | 唯一业务线被判定为体育 |
| W1=0的企业 | 2,730家 | 仅靠直接代码判定（文本无关键词） |
| W2=1.0的企业 | 6,163家 | 短文本+单个体育词即饱和 |
| W2=0的企业 | 2,730家 | 文本无关键词命中 |

> W1和W2经常同步饱和，SportRatio的细粒度区分能力有限。原始"主要业务活动"字段多数为简短行业描述，不是完整工商经营范围。
