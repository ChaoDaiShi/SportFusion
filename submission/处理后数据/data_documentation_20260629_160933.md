| 属性 | 值 |
|------|-----|
| 数据集名称 | 体育产业企业微观数据库 |
| 企业总数 | 76,687 |
| 体育企业数 | 8,950 |

## 字段说明

### 原始字段

| 字段名 | 含义 | 类型 | 说明 |
|--------|------|------|------|
| 统一社会信用代码 | 企业唯一标识 | string(18) | 全国统一18位信用代码 |
| 详细名称 | 企业全称 | string | 含注册地区及组织形式 |
| 行业代码 | GB/T 4754-2017 | int(4) | 国民经济行业分类代码 |
| 主要业务活动 | 主营业务描述 | text | NLP分析核心字段 |

### 预处理新增字段

| 字段名 | 含义 | 说明 |
|--------|------|------|
| 分词结果 | jieba分词输出 | 空格分隔的分词序列 |
| 关键词 | TF-IDF提取 | 分号分隔的Top10关键词 |
| 体育关键词 | 命中的体育词 | 来自271词体育词典 |
| 是否体育业务 | 体育判定结果 | 是/否 |
| 体育业态分类 | 9大业态分类 | 体育用品/健身休闲/体育赛事/... |
| 识别置信度 | 模型置信度 | 0-1连续值 |

### 测算新增字段

| 字段名 | 含义 | 说明 |
|--------|------|------|
| 体育业务占比 | sport_ratio | 0-1连续值 |
| 业务总线数 | 解析出的业务线数量 | 按分隔符拆分 |
| 体育业务线数 | 被识别为体育的业务线 | 逐条分类结果 |
| 是否跨界 | 跨界经营判定 | 是/否 |
| 跨界类型 | 跨界原因说明 | 纯跨界/潜在跨界/多元经营 |

## 清洗规则

1. **去重**: 基于全字段去重，无重复数据
2. **缺失值**: 文本字段填充空字符串，数值字段保持原值
3. **文本标准化**: 去除首尾空白，统一全角/半角符号
4. **行业代码**: 保留原始4位代码，范围 1491-9054

## 统计口径

- **体育产业**: 体育业务占比 >= 10% 或行业代码为直接体育代码的企业
- **跨界经营**: 行业代码非体育但文本含体育业务 或 间接代码+文本匹配 或 多业务线混合
- **产出指数**: sport_ratio * 100（因缺乏营收数据，采用归一化指数）
