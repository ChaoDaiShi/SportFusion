# 参考文献审计

## 保留原则

参考文献只保留能够直接支撑实际统计口径、数据处理方法或政策背景的来源。标准和政策优先使用国家统计局、全国标准信息公共服务平台及国务院正式页面；算法文献使用原始论文、出版社记录或项目官方仓库。

## 核验结果

1. GB/T 4754-2017 目前仍为现行标准，2023-12-28 复审结论为继续有效。
2. 《体育产业统计分类（2019）》由国家统计局令第26号公布，规定体育产业统计范围。
3. 国发〔2014〕46号和国办发〔2019〕40号可用于说明体育产业与统计治理的政策背景。
4. Gentzkow、Kelly 与 Taddy（2019）可支撑“文本作为经济研究数据”的方法论；Salton 与 Buckley（1988）可支撑词项加权方法。
5. jieba 官方仓库可支撑当前实现使用的中文分词和自定义词典功能。
6. Saaty（1980）只有在最终正文保留真实、可复核的 AHP 权重确定过程时才引用；若权重实际由人工设定，则删除 AHP 相关论证。

## 删除或降格处理

- BERT、Viterbi 等文献不再作为核心参考，因为当前识别实现并未训练或调用 BERT 分类器，也没有把 Viterbi 作为独立创新模块。
- Cohen Kappa、Landis-Koch 等文献只在存在可复核的双人标注记录时适用；当前没有该证据，因此相关指标和文献一并删除。
- Porter、产业集群等宏观文献与核心方法联系较弱，不作为论证主干。
- 无法核实题名、作者、卷期页码或正文无实际引用的条目不进入最终参考文献。
